# WORKSPACE · 造物间

个人 AI 创作资料库：人物形象、提示词、作品、素材、项目、工作流、灵感和实验记录。黑色文字首页，点击 EXPLORE 后进入创作库；启用登录时，只有登录后才能读取资料和图片。

## 本机运行

使用 Node 24.22.1，无第三方运行依赖：

```sh
npm start
```

打开 `http://127.0.0.1:4173`。默认仅监听本机，免登录预览。个人资料保存在 `data/library.json`，原图保存在 `data/uploads/`。新下载的源码不会附带个人资料。

## 个人登录

```sh
cp .env.example .env
npm run password:hash
```

在终端按提示设置至少 12 个字符的网站密码，把生成的完整哈希填入 `.env` 的 `OWNER_PASSWORD_HASH`，并设置 `OWNER_USERNAME`，然后运行：

```sh
npm run start:configured
```

密码只在终端输入，不要放进命令参数或 GitHub。登录验证使用 scrypt，登录凭据保存在 HttpOnly Cookie 中。退出或服务重启会使会话失效；连续闲置 2 小时或登录满 12 小时后需要重新登录。生产模式缺少登录或持久目录配置时会拒绝启动。

## 线上保存与部署

仓库提供 Render Blueprint：一个 Node 服务和一块持久磁盘，代码更新后自动部署。配置使用付费 Starter 服务和 1 GB 磁盘；创建前以 Render 控制台的费用为准。

完整步骤、环境变量、现有资料迁移、备份和恢复见 [DEPLOYMENT.md](DEPLOYMENT.md)。配置文件不会自行创建服务。实际服务创建并配置后，多个设备才会连接同一份线上资料。

线上使用 `NODE_ENV=production`，通过 HTTPS 访问。资料目录由 `LIBRARY_DATA_DIR` 指定，必须位于持久磁盘内；只运行一个实例，不能让多个进程同时修改同一份生产数据。更新源码不会覆盖资料目录。

## 使用与备份

- 支持新增、编辑、收藏、搜索、标签、状态、关联资料及 JSON 导入导出。
- 封面上传支持 PNG、JPG、WebP、GIF，每张最大 10 MB；详情和全屏查看均可下载原图。
- 上传与原图读取受同一登录保护，不使用公开图片地址。
- JSON 导出包含资料和图片引用，不包含图片文件。完整备份应同时复制 `library.json` 和 `uploads/`。
- 不预置图片，也未连接付费 AI 生成接口。

## 验证

```sh
npm test
```

测试自行创建临时目录与临时服务，验证登录、来源检查、访问保护、限流、会话过期、退出、重启后资料与图片保留、原图下载，以及原有资料操作。不会修改个人 `data/`。

## 源码

- `public/`：页面、登录交互和动效。
- `server.mjs`：资料、上传和静态文件接口。
- `lib/`：登录、密码验证、环境配置和持久写入。
- `render.yaml`：线上部署配置。
- `scripts/hash-password.mjs`：本机生成密码哈希。

`.env`、个人资料、上传图片、开发输出和本机工具均不提交到仓库。
